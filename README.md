# ACMTracker 🏆

ACMTracker is a locally hosted web application designed to monitor competitive programming performances and streamline the team formation process for major collegiate programming contests such as ICPC, IUPC, and NCPC. 

Built with a lightweight PHP and MySQL backend, it integrates directly with the Codeforces API to provide real-time insights into solver statistics, rating fluctuations, and overall contest readiness.

## 🚀 Features

* **Codeforces API Integration:** Automatically fetches and updates user data, including current ratings, max ratings, and total problems solved.
* **Performance Tracking:** Visualizes individual progress over time, making it easier to identify upsolving habits and consistency.
* **Strategic Team Formation:** Provides an organized interface to group individuals into balanced 3-person teams for ICPC, IUPC, and NCPC based on complementary skills and rating tiers.
* **Local Management Dashboard:** A centralized, easy-to-use interface for ACM Coordinators and coaches to oversee university-wide competitive programming activity.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3
* **Backend:** PHP
* **Database:** MySQL
* **External APIs:** [Codeforces API](https://codeforces.com/apiHelp)

## 📋 Prerequisites

To run this project locally, you will need a local server environment. 
* [XAMPP](https://www.apachefriends.org/index.html) (Recommended for Windows/Linux/macOS)
* Alternatively: WAMP, MAMP, or a standalone Apache/PHP/MySQL setup.
